# CareSync — Smart Medication Management System

CareSync is a multidisciplinary engineering project focused on developing an integrated medication management system to support people with cognitive challenges, reduced independence or difficulties managing medication routines.

The system combines three interconnected components:

- **CareBox:** An automatic medication dispenser designed to organise and assist with scheduled medication intake.
- **CareBand:** A wearable device that supports user identification and interaction with the CareBox through visual and haptic feedback.
- **CareApp:** A digital platform designed to manage medication schedules, monitor medication events and provide remote access to relevant information.

## System Architecture

CareSync connects hardware, embedded systems and software to create an integrated ecosystem.

The communication architecture includes:
- Wi-Fi connectivity between the CareBox and CareApp.
- Bluetooth Low Energy (BLE) communication between the CareBox and CareBand.
- Medication scheduling, user interaction and event monitoring across the system.
